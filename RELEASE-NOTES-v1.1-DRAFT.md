# EAIMS 1.1 — Draft Release Notes

> **Development draft. Not a release.** EAIMS 1.0.1 remains the current stable executable release.

## Theme

EAIMS 1.1 is being developed to strengthen organizational maturity assessment for adversarial and agentic AI without converting EAIMS into a duplicate application-security framework.

## Proposed additions

- adversarial exposure analysis;
- blast-radius governance;
- bounded agent credentials and privileged-action attribution;
- adversarial evaluation coverage;
- runtime abuse evidence;
- adversarial incident containment;
- AI-specific threat-intelligence disposition;
- dependency concentration risk;
- synthetic identity and representation controls where applicable;
- extensions to the G3 Autonomous / Agentic gate family;
- explicit activation/applicability semantics;
- stronger runtime-evidence expectations for high maturity.

## Compatibility

EAIMS 1.1 is additive-first.

- EAIMS 1.0.x assessments remain valid as 1.0.x assessments.
- Stable capability IDs are preserved.
- 1.1-only requirements do not retroactively change historical results.
- Migration requires explicit reassessment of newly applicable requirements.
- Existing counter-evidence remains part of the assessment history.

## Validation status

The development branch contains:

- RFC 0004;
- candidate requirement profile;
- anchor overlay;
- activation/applicability rules;
- evidence expectations;
- candidate machine-verification rules;
- positive/negative fixtures;
- reference-implementation regression mapping;
- worked assessor cases;
- assessor protocol;
- threat-intelligence operating protocol;
- external conceptual crosswalk;
- automated structural/regression tests.

Normative adoption requires successful CI, review resolution, worked-case validation, inter-rater analysis, regression validation, and a final release-readiness decision.
