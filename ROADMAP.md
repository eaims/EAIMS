## v1.1 — Adversarial & Agentic Governance
- Preserve the EAIMS 1.0.x normative baseline and backwards compatibility
- Add an adversarial/agentic development profile through RFC review
- Strengthen AI identity, privileged access, and blast-radius governance
- Introduce AI-specific threat-intelligence and emerging-risk practices
- Strengthen misuse/abuse resilience and runtime evidence expectations
- Extend agentic gates without duplicating specialized security frameworks
- Add synthetic identity, provenance, and influence-risk assessment where applicable
- Add dependency/concentration-risk analysis for material AI systems
- Validate changes with positive/negative fixtures, regression tests, and a 1.0 -> 1.1 crosswalk
