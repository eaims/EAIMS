# EAIMS Glossary

**AI maturity:** The institutional ability to repeatedly create, govern, operate, and improve value from AI.

**AI-native:** An operating state in which AI is embedded in strategy, products, processes, decisions, and organizational learning.

**AI system:** A technical and organizational system that uses AI models or services to produce outputs, recommendations, decisions, or actions.

**Agent:** An AI-enabled system that can plan or execute actions using tools, data, workflows, or other agents.

**Evidence:** Verifiable information supporting a maturity score.

**LLMOps:** Operational practices for developing, evaluating, deploying, monitoring, and governing large language model applications.

**MLOps:** Practices integrating machine-learning development and operations across the model lifecycle.

**RAG:** Retrieval-augmented generation, where retrieved information is supplied as context to a generative model.

**Responsible AI:** Practices addressing safety, fairness, privacy, transparency, accountability, human oversight, and societal impact.

**Shadow AI:** AI usage not approved, inventoried, or governed by the organization.

**Target maturity:** The contextually appropriate future capability level selected by an organization.
