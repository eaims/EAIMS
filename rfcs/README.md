# EAIMS Request for Comments

Material changes to dimensions, capabilities, anchors, scoring, gates, conformance, benchmark rules, licenses, or governance require an RFC. An RFC states the problem, evidence, proposal, alternatives, compatibility and IP impact, public review period, decision, and implementation status.

Draft RFCs are proposals, not normative requirements.
